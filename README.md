# 🎓 Salón de Estudio Colaborativo

Frontend del proyecto **Salón de Estudio Colaborativo en Tiempo Real**, desarrollado como mini-proyecto académico para la Facultad de Ingeniería.

La aplicación busca ofrecer un espacio virtual donde los estudiantes puedan estudiar en grupo mediante herramientas de comunicación síncrona como chat, videollamadas y compartición de pantalla.

---

# ✨ Características principales

- Registro e inicio de sesión de usuarios
- Gestión de perfiles
- Creación y administración de salas de estudio
- Chat en tiempo real
- Videollamadas y audio en tiempo real
- Compartición de pantalla
- Interfaz responsive
- Persistencia de mensajes
- Enfoque en accesibilidad y experiencia de usuario

---

# 🛠 Tecnologías utilizadas

- React
- TypeScript
- Tailwind CSS
- Vite
- Firebase Authentication
- Firestore
- WebSockets
- WebRTC
- ESLint
- Docker
